#   wesnoth:<path>  under the installed Wesnoth data ($WESNOTH_DIR, default /usr/share/games/wesnoth/1.16)
#   orig:<path>     under the originals directory given on the command line

# Method. Every source first goes through a gentle first order low pass (lowpass=f=5000:p=1 in process_sfx.py:
# minus 3 dB at 5 kHz, 6 dB per octave above, so a phone speaker has no crackly top end), then is shaped (leading silence to 2 ms, trailing silence cut, 5 ms fade in,
# the fade out in [sources]), measured, then given ONE plain gain: no compressor, no limiter. The measure for all of
# them is L100, the K-weighted (BS.1770) mean square of the loudest 100 ms window, in dB. Integrated LUFS is shown
# only where valid (it cannot read anything much under a second; ffmpeg ebur128 says -70 for a click). The
# reference is the median L100 of the nine Wesnoth sounds chosen. Each moment is brought to reference + its offset
# in [moments], plus MASTER_DB (-4). Where that gain would put the sample peak above -1.5 dBFS + MASTER_DB (that ceiling is lowered by a negative
# offset, so a tick meant to be quiet is quiet in peak too) the gain is reduced instead and the row says
# "peak-limited": sparse, spiky sounds (clicks, the dice, coins, the bell) end up quieter than their intent.
# Formats: up to 0.35 s a 16 bit mono 44.1 kHz WAV (exact, tiny), longer an Ogg Vorbis q6 mono 44.1 kHz.
#
